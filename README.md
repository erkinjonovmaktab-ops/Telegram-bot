# 🤖 Python Telegram Bot

Ushbu loyiha Python dasturlash tilida yaratilgan Telegram bot hisoblanadi.

## 📌 Loyiha haqida

Bot foydalanuvchilarga Telegram orqali qulay va tezkor xizmat ko‘rsatish uchun ishlab chiqilgan.

## 🛠️ Ishlatilgan texnologiyalar

- Python
- Telegram Bot API
- GitHub
- Render Hosting

## ⚙️ O‘rnatish

**1.** Loyihani yuklab oling:

```bash
git clone YOUR_REPOSITORY_URL
```

**2.** Loyiha papkasiga kiring:

```bash
cd YOUR_PROJECT_FOLDER
```

**3.** Kerakli kutubxonalarni o‘rnating:

```bash
pip install -r requirements.txt
```

**4.** Botni ishga tushiring:

```bash
python main.py
```

> Eslatma: `main.py` va `requirements.txt` nomlarini loyihangizdagi haqiqiy fayl nomlariga moslang.

## 🔐 Xavfsizlik

- Telegram bot tokenini ochiq joylashtirmang.
- Maxfiy ma’lumotlarni GitHub’ga yuklamang.
- Tokenni hostingdagi Environment Variables orqali saqlang.

## 🚀 Hosting

Loyihani Render platformasiga joylashtirish mumkin. Ishga tushirish sozlamalari botning turiga va kod tuzilishiga bog‘liq.
